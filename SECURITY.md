# Security Policy

## Authorized use

PenX is intended for authorized reconnaissance, defensive security research, and lab environments. Scan only systems you own or are explicitly permitted to test.

## Reporting a vulnerability

Please **do not disclose a new sensitive vulnerability or working exploit against PenX in a public issue**. If GitHub's **Report a vulnerability** / private vulnerability reporting feature is enabled for this repository, use it. Otherwise, open a public issue with **no sensitive technical details** requesting a private reporting channel.

When a private contact channel is available, include a clear impact summary, affected component, reproducible steps, and relevant version information. Remove tokens, hosts you do not control, credentials, and personal data from examples.

## Scope and limits

PenX invokes independent upstream scanners, which have their own maintainers, licenses, and security update processes. Issues in Nmap, Npcap, WhatWeb, or Nikto should also be evaluated against those projects' own advisories and disclosure guidelines.

AI-generated findings may be inaccurate. Independently validate any security conclusion before treating it as confirmed.
